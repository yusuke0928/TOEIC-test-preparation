# TOEIC L&R 900 対策

TOEIC® L&R で **800 点台から 900 点台へ抜ける**ための演習アプリです。

すでに基礎は固まっていて、あと少しの取りこぼしが 900 の壁になっている人に向けて作りました。
そのため「基礎からやり直す」機能はありません。代わりに、**どの論点で何問落としているかを可視化し、忘れる直前に出し直す**ことに集中しています。

ビルド不要の静的サイトです。HTML と JavaScript のファイルを置くだけで動きます。

## 収録内容

| 区分 | 内容 | 問題数 |
|---|---|---|
| 個別論点ドリル | 37 論点 | 634 問 |
| 予想模試 | 5 回分（各回 200 問） | 1,000 問 |
| **合計** | | **1,634 問** |

論点は 5 つの群に分かれています。

- **文法**（12 論点・Part 5・6）— 品詞 / 動詞の形 / 仮定法 / 準動詞 / 分詞 / 関係詞 / 接続詞・前置詞 / 代名詞 / 比較 / 数量詞 / 倒置 / 態
- **語彙・語法**（7 論点・Part 5・6）
- **文脈**（4 論点・Part 6）— 接続語 / 文脈依存の時制 / 文挿入 / 結束性
- **読解設問**（7 論点・Part 7）— NOT・EXCEPT / 意図問題 / 位置選択 / 同義語 / クロスリファレンス ほか
- **リスニング**（7 論点・Part 1〜4）— 状態と動作 / 間接応答 / 意図問題 / 図表問題 ほか

予想模試はすべて本番と同じ構成です。

> Part 1: 6 問 / Part 2: 25 問 / Part 3: 39 問 / Part 4: 30 問 / Part 5: 30 問 / Part 6: 16 問 / Part 7: 54 問

全問に日本語の解説が付いています。「なぜそうなるか」の本文、**選択肢ごとの検討**、全訳、語注の 4 点セットです。

## 主な機能

### 3 つの演習モード

| モード | 用途 |
|---|---|
| **個別論点ドリル** | 論点を 1 つ選んで潰す。1 問ずつ即時採点＋解説。全問／ランダム 10 問／未着手のみ／間違えた問題のみを選べる |
| **予想模試** | フル 200 問（120 分）／リスニングのみ／リーディングのみ（75 分）／パート指定。本番形式では最後にまとめて採点し、換算スコアを算出 |
| **復習キュー** | 期限が来た設問・一度でも間違えた設問・フラグを付けた設問を出し直す |

### 間隔反復（SRS）

正解するたびに、次に出題されるまでの間隔が **1 → 3 → 7 → 16 → 35 → 75 日**と伸びていきます。
間違えた設問は **20 分後**に戻ってきます。忘れかけたところで当てるのが、最も定着します。

### 学習分析

- パート別・論点別の正答率と、**900 点到達ラインとの差**
- 換算スコアの推定（セクションごとに 20 問以上こなすと算出。データ不足のときは無理に数字を出しません）
- 1 問あたりの解答時間と本番ペースの比較、**正解時と誤答時の所要時間の差**（迷いの指標）
- 学習量のカレンダー、曜日別・時間帯別の分布、連続学習日数

### 音声（Web Speech API）

リスニングは**端末に内蔵された音声合成**で読み上げます。音声ファイルを持たないため、リポジトリが軽く、オフラインでも動きます。
米・英・豪・加の 4 アクセント × 男女に加えてナレーターの 9 ロールを、端末の音声へ自動で割り当てます。再生速度は ×0.85〜×1.3 で切り替えられます。

Part 1 の写真は使えないため、代わりの手段で描写の根拠を示しています。

- **予想模試**（30 問）は、**描写の根拠が読み取れる線画 28 種**を SVG で代替しています。本番の見た目・時間感覚を再現するため
- **個別論点ドリル**は、英語の場面描写文を数秒表示してから消す方式です。線画では「着ている（is wearing）」と「着ようとしている（is putting on）」のような動作の識別を描き分けられないための工夫で、消えた後も **「もう一度見る」で何度でも再表示**できます（音声非対応の端末で解答不能にならないため）

### そのほか

- **読んで解くモード** — 音を出せない場所（電車内など）で、選択肢とスクリプトを表示して解けます。音声非対応の端末では自動で有効になります
- **2 つの配色** — 昼（紙）と夜（墨）。左下のボタン、または設定画面から切り替え
- **中断と再開** — 演習の途中で抜けても、同じ問題・同じ進捗から再開できます
- キーボード操作（`A`〜`D` / `1`〜`4` で解答、`←→` で移動、`Space` で音声、`F` でフラグ）

## 使い方

### そのまま使う

公開されている URL をブラウザで開くだけです。インストールは不要です。

### 手元で動かす

`file://` では ES モジュールが読み込めないため、簡易サーバーを立ててください。

```sh
git clone https://github.com/<user>/TOEIC-test-preparation.git
cd TOEIC-test-preparation
python3 -m http.server 8777
```

ブラウザで `http://localhost:8777/` を開きます。

### 学習記録の保存場所

記録は**この端末のブラウザ内（localStorage）にのみ**保存されます。サーバーには何も送信しません。
そのため、次の点に注意してください。

- ブラウザの「サイトデータを削除」や、シークレットウィンドウを閉じると記録は消えます
- **端末をまたいで記録は共有されません**

### PC とスマホの両方で使う

設定画面から手動で移します。

1. 使い終わった端末で **「JSON を書き出す」**
2. そのファイルをもう一方の端末へ送る（メール・クラウドなど）
3. もう一方の端末で **「読み込んで合流」**

合流では受験記録が**両方とも残り**、設問ごとの習熟度は**最後に解いた方**が採用されます。
（「読み込んで上書き」は、この端末の記録を捨ててファイルの内容に置き換えるバックアップ復元用です。）

模試を受けたら書き出しておくと安全です。

## 音声についての注意

- 音声は**端末に内蔵された合成音声**であり、**実際の試験音声とは異なります**。話速・抑揚・間の取り方は本番と同じではありません
- 割り当てられるアクセントは**端末にどの音声が入っているかに依存します**。たとえば豪州英語の音声が無い端末では英国英語で代用されるため、実際には 2〜3 アクセントになることがあります
- 本番に近づけたい場合は、OS に各国の英語音声を追加してください
  - macOS: システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 英語
  - Windows: 設定 → 時刻と言語 → 音声認識
- 英語音声が 1 つも見つからない端末では、自動的に「読んで解くモード」になります

## 構成

```
index.html
assets/css/app.css          デザイン（紙 / 藍墨 / 朱の 3 色、昼・夜の 2 テーマ）
assets/js/
  app.js                    ルータと起動処理
  quiz.js                   出題エンジン
  store.js                  localStorage と間隔反復
  analytics.js  score.js    集計と換算スコア
  audio.js                  Web Speech API
  charts.js  render.js  ui.js  runtime.js
  views/                    home / drills / mocks / review / analytics / settings / result / exam
assets/data/
  topics.js                 論点マスタ
  scenes.js                 Part 1 の場面イラスト（SVG）
  registry.js               問題データの目録と遅延読み込み
  drills/*.js               論点別ドリル
  mocks/volN*.js            予想模試（volN.js が集約、volN-xx.js が中身）
```

模試 1 回分は数百 KB あるため、必要になった時点で動的に読み込みます。

外部ライブラリは使っていません。グラフはすべて自前の SVG です。
Web フォント（Google Fonts）のみオンラインで読み込みますが、読み込めない環境では端末標準のフォントで表示されます。
