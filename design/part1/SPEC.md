# Part 1 線画の設計仕様

出典: Claude Design プロジェクト「検証ルール付き場面設計」（2026-08-14）
このファイルと同じディレクトリの SVG 5点が、その成果物をローカルへ写したもの。
**以後この文書が正。Claude Design を再度開く必要はない。**

判定に必要な情報は「絵の雰囲気」ではなく**幾何的な事実**として描く。
曖昧に見えたら規則を疑わず、数値を満たしていない実装を直す。

## 前提

| 項目 | 値 |
|---|---|
| viewBox | `0 0 460 280` 固定（既存30問がこの座標系に依存） |
| 表示幅 | 最大 544px（等倍）。**この縮尺で判別できることが絶対条件** |
| 色 | CSS 変数のみ。ハードコード禁止、外部参照禁止 |
| 線幅 | 3段だけ — 補助 1.5（`--rule-soft`）／主線 2／天面・動作腕 2.5〜3 |
| 塗り | `var(--card-2)` のみ |

## ① 動作主の有無

- 人物の**頭部と胴は必ず `fill="var(--card-2)"`**。背後の什器線を塗りで断ち切る
- 最小寸法: 頭部 r ≥ 8 ／ 肩幅 ≥ 28 ／ 胴の高さ ≥ 38 ／ 動作している腕は線幅 3
- **無人版は什器を1単位も動かさず、人物レイヤーだけ抜く。**差分が人だけなので
  `is being + 過去分詞` の可否が確実に決まる
- 無人版には静止を示す小物（パレット上の箱など）を1つ置き、作業が終わった状態を明示する

## ② 接触／非接触

- 手 = `var(--card-2)` の円 r=4.5。**対象より後に描く**
- 接触: 手の円が対象輪郭に **1〜2 単位**重なる
- 非接触: 隙間 **14 単位以上**。対象の輪郭は切らない。腕は伸ばした直線に近づける
- **腕の上限: 肩→肘 30 ／ 肘→手 28（合計 58）。届かない距離に手を置かない**
- 接点マーカー `cue` = 朱の点 r=2.5。**1場面 1〜2 個まで**。フラグで消せるようにする

## ③ 前後・内外

- 手前の面は `--card-2` で必ず塗る。**奥の線は塗りで消える**
- カウンター内の人物は**脚を描いたうえで前面の塗りに飲ませる**
  （天面に立って見えた原因は、脚を塗りで隠していなかったこと）
- 手前の人物は接地 y を奥より **+20 以上**下、寸法を **1.1 倍**
- 奥の床線は手前の床線より上（y が小さい）に**別線**で引く
- **手前の人物の頭部・胴に、奥の什器の輪郭を重ねない。**塗りが同じ `--card-2` なので
  重なると2つの物体が1つの塊に見える。什器の端は胴から **8 単位以上**離す

## ④ 姿勢 — 頭頂の高さと膝の角度、2つだけで区別する

床 y=250 を基準にした本番座標での頭頂 y:

| 姿勢 | 頭頂 y | 特徴 |
|---|---|---|
| 立つ | 124 | 膝ほぼ直線 |
| 座る | 150 | 腿が水平・支持面あり |
| しゃがむ | 172 | 腰が落ち膝が前上 |
| かがむ | 166 | 膝は伸び胴が60°前傾 |

頭頂差が 20 以上あれば 544px でも判別できる。
**しゃがむ／かがむは頭の高さが近いので、膝の曲げと頭の水平方向オフセットの両方で必ず分ける。**

## ⑤ 数と配置 — 箱は必ず三面で描く

- 箱 = 前面矩形 ＋ 天面パラレログラム（dx 8 / dy −8）＋ 右側面。前面中央に折り目線を1本
  （**三面あれば窓と混ざらない**。トラックの窓に見えた原因は前面のみだったこと）
- 積まれている: 垂直辺を揃え、辺を共有して隙間 0
- 並べられている: 同一の底辺 y、等間隔 10〜14
- 散らばっている: 各要素を ±12° 回転させ、底辺 y を 6 以上ずらす

## 描画順（＝z 順）— 場面ごとに変えない

1. 奥の床線・壁・棚（線のみ）
2. 奥の什器と、その上の物
3. **人物**（全身を描く。隠すのは次の層の仕事）
4. **手前の面**（カウンター前面・台の幕板・箱）— `--card-2` の塗りで奥を消す
5. 前に出る腕・手・接点マーカー、手前の床線

## 部品セット

- **figure**（人物）: 頭・胴・脚・腕の4部品。姿勢5プリセット（stand / sit / crouch / bend / lean）。
  引数は接地 x, 接地 y, 向き, 倍率。**腕だけは終点座標を渡して都度描く**
- **fixture**（什器）: counter, bench, shelf-3tier, table, stool, pallet, doorway。
  すべて「天面線＋前面の塗り」の同じ構造なので、幅と高さのみ差し替え
- **prop**（小物）: box, cup, beaker, tube-rack, machine, monitor, books, carton-stack。
  箱は三面描画関数を1つ持てば足りる
- **marker**（接点）: hand（`--card-2` の円 r=4.5）と cue（朱の点 r=2.5）

## 共通座標

```
手前の床線   y = 250〜262
奥の床線     y = 232〜236
天面（腰高） y = 172〜182
棚・壁の上端 y = 48〜104
人物の全高   126〜138（280 の 45〜49%）
腕の上限     肩→肘 30 / 肘→手 28
```

## 量産の手順

1. 場面ごとに**正解文と誤答文を先に書く**
2. その文が要求する読み取り項目（①〜⑤）を選ぶ
3. 選んだ項目の規則を満たす部品だけを置く。関係のない装飾は置かない
4. ①が絡む場面は**有人／無人を対で作る**。什器座標は共有する
5. 544px と light / dark で見て、規則の数値を満たしているか確認

## 受け入れチェック（1場面ごと）

- [ ] 正解文の根拠が絵の中に幾何的にある
- [ ] 手と対象の距離が 0〜2 か 14 以上のどちらか
- [ ] 手前の面が奥の線を塗りで隠している
- [ ] 人物の接地 y が層ごとに 20 以上離れている
- [ ] 箱が三面で描かれている
- [ ] 色指定は CSS 変数のみ、外部参照なし
- [ ] light / dark 両方で線が見える
- [ ] 544px で姿勢が判別できる

## 対象外

着用状態と着用動作（`is wearing` / `is putting on`）の描き分けは、線画では表現できないため
方針・見本ともに対象外。ドリルの描写テキスト方式（`drills/part1.js`）で扱う。

## 申し送り

**`var(--ai)` にダーク値が必要。** `#1f4b6e` は dark の面 `#212832` 上でほぼ見えない。
dark は `#6f9fc4` 程度を推奨。値が決まるまで場面本体では藍を使っていない。
